# Windows 个人画布测试版

优先双击桌面「个人画布（测试版）」快捷方式，或打开同目录 `程序文件/InfiniteCanvas Personal.exe`。这是无需解压等待的完整程序目录，请保留其中的配套文件。无需安装 Node、Go 或注册账号。

另提供单文件 `InfiniteCanvas-Personal-0.1.4-Windows-x64.exe`，每次启动需先解压到独立临时目录。此版本为未签名的 Windows x64 测试程序。

## 0.1.4 ComfyUI 模型菜单提示

连接 ComfyUI 但还没有登记工作流时，默认模型和画布节点菜单会明确提示导入 API JSON、拉取参数并启用工作流。ComfyUI 安装的模型文件名不是可直接执行的生成任务。

## 0.1.3 ComfyUI 模型列表修复

免登录个人版中，已启用的本地 ComfyUI 图片和视频工作流会显示在「默认模型」及画布节点模型菜单中。远端系统渠道的登录权限规则保持不变。

## 0.1.2 云端 ComfyUI 连接修复

修复重复打开便携 EXE 时，共享临时解压目录被清理导致启动文件丢失的问题。每次启动使用独立临时目录，重复打开会切回已有窗口。启动失败时先退出后台再显示错误，并补充本机连接服务的错误日志。首次启动需等待解压完成。

## 测试入口

- 打开右上角「配置」，可快速添加 DeepSeek、GRSAI 国际版、AA、火山方舟；填写自己的接口地址、API Key 和模型名。
- 「导入 CC Switch」支持 OpenAI Chat Completions 兼容的分享链接和 JSON，可预览后追加导入。暂不支持 Responses、Anthropic、Gemini、Codex TOML 或 SQL 备份。
- 新增 ComfyUI 渠道，点击「选择」进入连接界面。Windows 版会自动启动和连接本机服务。
- 直接连接：填写 ComfyUI 服务地址与可选 Bearer API Key，点击「测试连接」。
- 云端 SSH：填写云控制台提供的主机、SSH 端口、用户名、密码或私钥，以及远端 ComfyUI 端口，建立隧道后测试连接。SSH 密码及私钥口令只用于当前连接，不保存。
- 点击「启用云端生产」，导入 ComfyUI JSON 文件，再点击「拉取参数」登记工作流。启用工作流后可在画布图片或视频节点的模型选择器中调用。
- 桌面版内置 Bridge 直接通过 ComfyUI 标准 API 向云端提交任务；结果服务优先使用本机 8189 端口，被占用时自动选择其他可用端口。

## 数据与退出

个人数据保存于 `%APPDATA%\InfiniteCanvasPersonal`，包含本机数据库、画布配置和连接设置。API Key 保存在本机。备份时关闭程序，再备份此目录。

关闭窗口会同时结束画布后台、Bridge 和 SSH 隧道；运行云端任务期间请保持窗口打开。启动日志位于上述目录的 `desktop.log`。

## 开发打包

安装 web、canvas-agent、desktop 三个目录的依赖，准备 Go 和 Node 22 LTS。在 desktop 目录运行 `npm run build`，输出到 `desktop/dist`；构建脚本也会准备 ComfyUI Bridge。运行 `npm run smoke` 可用隔离的测试目录执行桌面模拟联调，不调用付费 API。
