# 待测试

- RunningHub 设置页增加公开工作流目录搜索。选择条目后会填入工作流 ID、名称和推断用途；搜索不提交生成任务。拉取参数仍需用户自己的 RunningHub API Key。目录发现不代表能在星云云端 ComfyUI 执行，还需确认 API JSON、节点和模型兼容性。
- ComfyUI Bridge 连接云端后会按 `/object_info` 检查必填输入、枚举值、动态输入组和模型名称，再登记 Anima、MOSS、千问 2.1 图片生成与 MiniMax H3 多参考图视频。千问 2.1 改为使用文本编码节点提供的匹配 latent。Anima 已通过个人版会话、工作流任务接口、本机 Bridge、云端执行和结果 URL 获取完成真实调用；另一次 1024×1024/30 步直接云端任务也已返回 PNG。MOSS、千问 2.1 与 H3 的真实生成、画布选择器操作和媒体类型/预览仍待测试。H3 默认 736×1280、243 帧、4 步、最多四张图片和可选参考音频。

- 本地模型渠道新增 DeepSeek、GRSAI 国际版、典名词元（AA）预设；请分别填写 API Key 并验证文本模型列表、连接测试及适用的创作入口。AA 按官方 OpenAI Chat 路径及 Bearer 认证接入。
- GRSAI 视频渠道适配 `wan-3.0`、`minimax-h3`、`agnes-video-2.5`，通过 `/v1/api/generate` 创建任务并通过 `/v1/api/result?id=...` 轮询。已完成本地免登录请求链路实现；真实账号、参考素材组合、时长/清晰度与实际结果下载仍待账号持有人验证。
- 火山方舟可快速添加，CC Switch 导入会识别其域名并保留渠道类型；已有文本模型、Seedance 视频 API 适配，请验证聊天、模型列表及视频任务创建/轮询。
- CC Switch 导入支持粘贴服务商分享链接和上传 JSON 配置；请验证单渠道、多渠道预览与追加导入，确认既有渠道不会被覆盖，预览不会展示 API Key 明文。
- 当前仅适配 OpenAI Chat Completions 兼容渠道；Responses、Anthropic、Gemini 与 SQL 备份不在本次支持范围。GRSAI 专用音频异步协议尚未适配。

- ComfyUI 新增本机 API 地址与 Bearer API Key 测试、运行/排队数量查看、SSH 隧道。Windows 个人版自动启动并连接本机 Agent；网页版仍可手动配置 Agent。测试地址、Key 与队列请求仅通过本机连接服务转发。
- SSH 隧道支持密码、私钥文件、加密私钥口令与本机 ssh-agent；密码和口令仅用于本次连接，不保存。使用首次信任的主机指纹校验，后续指纹变化会拒绝。已用本机 SSH 测试服务验证密码/私钥转发、错误密码与指纹变化拒绝；仙宫云等真实云实例仍待验证。
- Windows 个人版自动建立仅用于本机的个人会话，无需注册和登录，可登记、拉取、提交工作流。「启用云端生产」复用本机连接配置，支持导入 API JSON/界面 JSON 文件；启用后可在画布图片/视频节点选择工作流。网页版原有登录流程保留。

- Windows x64 便携 EXE：内置前端、Go 后端与本机连接服务；仅监听回环地址，窗口关闭时结束后台和 SSH 隧道；固定本机画布地址以保留浏览器数据库，数据保存于 `%APPDATA%/InfiniteCanvasPersonal`。请测试重启后的画布、素材、渠道配置保留。
- 桌面模拟联调已验证免登录、自动 Agent、Bearer Key 传递、队列状态、Bridge 上线、工作流字段解析、任务完成及 PNG 结果下载，并拒绝跨站访问本机入口。未使用真实付费 API 或云 GPU；结果不代表上述真实服务已联调通过。
- 已通过 Go 业务/处理器/配置测试、独立 Bridge 测试、11 项渠道/CC Switch 测试和 SSH 转发测试。前端生产构建通过；原项目仍有部分非本次新增的 TypeScript 检查错误，构建沿用其忽略类型错误设置。
- 2026-11-14：最终便携 EXE 已实际启动，免登录会话成功；关闭窗口后 9 个关联进程全部退出。解包桌面应用启动与本机 Agent 在线检查通过，ComfyUI/SSH 表单可见性检查通过。测试版和说明已放入桌面 InfiniteCanvas个人版测试-0.1.0 文件夹。
- 2026-11-14 后续复现：0.1.0 便携版重复打开时，共享临时目录会被其他启动器清理，导致 Agent 或 Next 入口丢失；0.1.1 已改为独立的 NSIS 临时目录并加入解压启动提示。桌面另提供完整程序目录和快捷方式，已实际验证启动、免登录、Agent 在线与退出。
- 0.1.1 最终桌面副本回归通过：实际单文件启动、重复打开两次后原窗口和资源仍可用、Agent 在线、关闭后后台退出；桌面目录版也通过免登录与退出检查。

- 0.1.3 修复免登录个人版模型选择器把本地 ComfyUI 工作流候选过滤掉的问题，默认模型和画布节点选择器共用该逻辑。便携 EXE 已通过启动、免登录会话、重复启动和退出回归；仍需在已连接且已启用图片/视频工作流的实例上确认两个菜单展示和实际生成调用。
